SHEF 2.0 · day-ahead load forecast monitor

Every day at 10:00 Central, tomorrow's hourly electricity load for ERCOT's South Central weather zone (Austin, San Antonio) is forecast using only data available at that moment, and checked against what actually happened. Rows marked backtest are the Aug 2025 – Oct 2026 holdout, scored once on archived weather forecasts; live rows are real forecasts.

Shadow challengers

Frozen rules applied to the champion's forecast at issue time, logged daily, never served. recent_median: the forecast minus half the median error of the last 7 days that were known by 09:00 CT. stack_ercot: 0.31 × ours + 0.70 × ERCOT's 09:30 forecast (ours alone where ERCOT is missing). Both were fixed on 28 Oct 2026. Record counts only rows logged before their target day, from 29 Oct, and is what the promotion rule judges after 28 days: ≥ 0.10 MAPE points better than the champion, with Peak-MAPE no worse. Incl. replay adds earlier live days recomputed afterwards with the same point-in-time rule.

Promotion log

Load publishing latency

Every feature cuts load off 1 hour before issue time, assuming GridStatus publishes each hour within 60 minutes. Each daily load fetch tests that for free: the newest hour it sees was published within the first figure, and the following hour was still missing after the second. A second figure ≥ 60 min would break the assumption.
